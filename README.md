# peeyusha.vercel.app

This is my portfolio. It has my ML research, the apps I've built, the design work I did for Scorpions and Nakshatra, and a small scrapbook corner about me.

I built it with Astro, and the animations use GSAP and Lenis. The CSS is written by hand.

To run it locally:

```bash
npm install
npm run dev
```

It opens at http://localhost:4321. `npm run build` puts the static site in `dist/`.

Every push to `main` goes live on Vercel.
